How to Use the Card Creator

1. Choose Character or Setting and edit the fields. The central card updates instantly.

2. Upload artwork, move and resize it using the Artwork Placement sliders or by dragging on the preview; adjust the frame colour and ornamental design, choose up to three character traits, and write two interactions grounded in the novel. Select words in either field to make them bold or italic. The card automatically adjusts font size to keep both complete.

3. Select Save Draft to keep changes in your browser, or Download PNG for a high-resolution printable card. Character card stat numbers are optional and hidden by default. Export Card Data creates a JSON file you can share or import later.

This is an initial working prototype. It does not yet provide accounts, online collaboration, or shared classroom decks.
